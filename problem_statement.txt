Customer Segmentation & Personalization Agent for Retail Banking
Business Summary
A leading retail bank provides a range of financial products such as savings accounts, credit cards, personal loans, and investment services. However, the bank currently applies broad, one-size-fits-all marketing strategies, resulting in low customer engagement and suboptimal product adoption. The bank seeks to leverage its customer data to better understand behavioural patterns, segment customers into meaningful groups, and deliver personalized product recommendations. The goal is to improve customer experience, increase cross-selling opportunities, and enhance overall business performance through data-driven decision-making.
Objective
Participants are required to design and implement an AI-powered agent that:
1.Performs automated exploratory data analysis (EDA) on customer data
2.Segments customers based on behavioural and financial attributes
3.Generates interpretable customer personas
4.Recommends personalized banking products or strategies for each segment
5.Produces human-readable insights and summaries
6.The agent should simulate how a bank’s analytics team would derive actionable insights with minimal manual intervention.
Requirements
Participants must build an agent-driven system that can observe data of bank customers and segment them on various features. The agent must parse the user's natural language query to extract intent and key filters, then execute a clear pipeline of steps tailored to answer that specific query. The system should invoke only the relevant tools needed for the analysis.
Minimum Functional Requirements
1.Automated data ingestion and preprocessing
2.Interaction via Chat, API or a functioning front-end application
3.Dynamic EDA from user queries (missing values, distributions, correlations)
4.Creating data preprocessing pipelines
5.Basic rule-based or ML-based recommendation engine
6.Segment profiling and persona generation using ML, statistical methods, rules, or a hybrid approach
7.Recommendation logic for cross-selling/up-selling financial products
8.Explainability (why a customer belongs to a segment)
9.Model evaluation
10.Visualization
Example Queries:
User Query	Expected Agent Behaviour
"Segment customers into priority, regular and dormant customers based on balance being maintained and frequency of transactions"	1.Reads the data and identifies relevant columns (customer balance, transactions)
2.Aggregates data and performs necessary feature engineering (group by customer and creates maximum monthly balance, transaction frequency, average transaction amount columns)
3.Performs rule based or ML based clustering
4.Returns a CSV of customers and segments
At any point, if more input is needed from the user, the agent should ask (human-in-the-loop)
“On what basis were priority customers selected?”	Returns the rules used for determining priority customers (if ML algorithm was used, it should return some distinguishing features of priority customers)
“What is the average size of transactions for priority and regular customers?”	Agent must analyse the data, perform aggregation functions and provide a response
“Which regular customers can be converted to priority customers? What should be done for the same?”	Agent returns a list of regular customers that have potential to be priority customers and provides advice on how to encourage the behavioural transition

Expected Agent Architecture
1.EDA Tool: Performs an analysis on the data and understands the composition of customers
2.Feature Engineering Tool: Performs feature selection and feature transformations to derive the most definitive features of a customer
3.Segmentation Tool: Generates rules or develops a clustering model to divide the customer base into groups – identify edge cases
4.Explainability Tool: Explains why a particular customer belongs to a segment
Recommended Output from the Agent
1.Clear description of each customer segment
2.Customers sorted into respective segments
3.Summary of EDA performed on the data
4.Findings and insights about each segment
5.Recommendations for customer retention
